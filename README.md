With the development of 5G and IOT technologies, a greater number of devices are now interconnected in Mesh Network topology
As a result , the connected devices are prone to such DDoS attacks
One such attack is named “Gray Hole”
Protection against such Gray Hole Attacks is an ongoing research topic
 Our model, combined with Machine Learning, helps predict the malicious activity of a node with approx. 70% success rate
Future scope would include addition of mitigation techniques resulting in isolation of malicious nodes from an active network in real-time
